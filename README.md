# WatchFlix  
WatchFlix is a movie streaming platform designed as a community-driven alternative to Netflix. Built with ASP.NET Core MVC, the application allows users to sign up, upload movies, and manage movie details. Users can explore a wide range of films, add comments, and rate them, creating an interactive experience. Leveraging AWS services, WatchFlix ensures efficient storage and management of movie data, fostering a vibrant movie community.

---

## Features  

- **Secure User Authentication**: Sign up and log in with ease and security.  
- **Movie Management**: Upload, edit, and manage movies and banners conveniently.  
- **Interactive Ratings & Comments**: Engage with movies by adding comments and ratings.  
- **AWS S3 Integration**: Store movie files and banners securely in the cloud.  
- **Efficient Metadata Management**: Store movie details like name, genre, rating, director, and release date in **DynamoDB**.  
- **User Data Security**: Safeguard user information with **AWS RDS**.  
- **Configuration Flexibility**: Manage app settings via **AWS Parameter Store**.  

---

## Technology Stack  

- **ASP.NET Core MVC**: Robust backend framework for development.  
- **AWS S3**: Reliable cloud storage for movies and images.  
- **AWS DynamoDB**: Efficient database for movie metadata.  
- **AWS RDS**: Secure relational database for user data.  
- **AWS Parameter Store**: Centralized configuration management.
